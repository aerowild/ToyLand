# Math Quest - Grade 1 & 2

3D math game for 7-year-olds built with React + Vite + Three.js.

## Quick Start

```bash
npm install
npm run dev
```

Opens at **http://localhost:8888**

## Change Port

Edit `vite.config.js` → `server.port`.

## Build for Production

```bash
npm run build
npm run preview
```
